# 学术论文

审稿人读它是为了**决定录不录用**：这份工作是否新、是否正确、是否重要、是否可复现。

## 1. 骨架与每节的失败模式

| 节 | 要回答什么 | 失败模式 |
|---|---|---|
| 摘要 | 问题—方法—结果—意义，四句内说清 | 只有背景和方法，没有结果数字 |
| 引言 | 领域现状 → **具体空白** → 你的贡献 | 空白写成「研究较少」，没说清为什么难 |
| 相关工作 | 别人做到哪、差在哪 | 罗列式综述；批评对手时不给证据 |
| 方法 | 让人能复现 | 关键设计选择不写理由；参数来历不明 |
| 实验 | 设置、基线、指标、结果 | **基线不公允**（数据/算力不同却不说明） |
| 讨论 | 结果意味着什么、边界在哪 | 把局限写成「未来工作」，回避真问题 |
| 结论 | 一句主张 | 复述摘要 |

## 2. 贡献与空白必须对得上

**贡献要能一句话说清，且可证伪。**
「提出了一种新方法」不是贡献；「在同等数据与算力下，相对最强基线提升 X，且不增加推理成本」才是。

**引言的空白要具体。**「该方向研究较少」是无效陈述——少不等于值得做。
要写清：现有方法在什么条件下失效、这个失效为什么重要、你的方案为什么能补上。

**每一处空白都要有对应的贡献。** 列了三个空白却只给一个贡献，说明其中两个是为了铺垫凑的。

## 3. 实验的可信度

以下是**审稿人普遍会质疑的点**，按它们准备，而不是当成会议强制项：

- **基线要公允**：同数据、同算力、同评测协议；不同就写明差别。
- **报方差**：单次结果、单一种子会招致怀疑——给误差棒、置信区间或多种子均值。
- **消融对应方法里的每个部件**：读者会用消融表检验你的增益是不是真来自你声称的来源。
- **增益要归因**：证明提升来自你的方法，而不是换了数据、调了参数这类附带变量。

> ⚠️ **别把这些当成会议的硬性要求**：主流会议的官方 checklist 通常不强制要求报 p 值、
> 特定数量的种子、或必须做消融。它们影响的是**审稿人的判断**，不是形式上的合规。
> 具体以当届 CFP / checklist 原文为准（见 §4）。

## 4. 真正的形式硬要求

这几项是**会直接导致行政拒稿**的，与内容质量无关：

- **checklist 必交**——不少会议不交直接 desk reject。
- **Limitations / 局限段**（部分会议要求单列一节）。
- **rebuttal 的格式限制**（如仅纯文本、禁止外链），违反直接 desk reject。
- **匿名化要求**：双盲审稿时，自引、致谢、代码链接、数据来源都要处理。
- **页数限制**：正文与参考文献、附录分别计算。

**先读当届 CFP 与 checklist，再动笔。** 不同会议、不同年份的要求差异很大。

## 5. 写作纪律

- **术语首次出现给定义，全篇一种叫法。** 同义词轮换在论文里是缺点不是优点。
- **图表自足**：脱离正文也能读懂；坐标轴带单位；关键结论直接标注在图上。
- **投稿信不要把摘要抄一遍**，写「为什么这篇适合本刊、为什么重要、有无利益冲突」。
- **审稿回复**：逐条编号回应，先接受再解释；不同意的要给出证据而非情绪。
  能改就说明改了哪一处（页/行），不能改就说清理由。

## 6. 与专利的时序关系

**先申请专利，后投稿。** 论文发表构成在先公开，会使自己的方案丧失新颖性。
**中国的宽限期不覆盖论文发表**——专利法第二十四条只列四项（紧急状态、国际展览会、
**规定的**学术会议、他人泄露），普通论文、arXiv、学位论文、公开演示都不在其中。
⇒ 手上有待发表的稿子，先确认专利申请日已定。

## 7. 交付前自检

- [ ] 摘要里有没有具体的**结果数字**？
- [ ] 引言是否指出了**具体的空白**，而不是「研究较少」？
- [ ] 每处空白是否都有对应的贡献？
- [ ] 与最强基线的比较是否同数据、同算力？说清楚了吗？
- [ ] 结果是否带方差？
- [ ] 消融是否对应方法里的每个部件？
- [ ] 局限是写进讨论，还是被藏进了未来工作？
- [ ] 当届 CFP 的 checklist、页数、匿名化要求是否逐条核对过？
