# 措辞：把机械味拆掉

**横切层**：任何体裁成稿后都在这里过一遍。它不是体裁 reference，不替代路由表里的那六份。

## 0. 设计原则（先读，否则后面会滥用）

**可操作单位是「构式」，不是词。** 只给禁用词表必然失效——模型会换下一个差一档的习惯：
禁了破折号改用分号，禁了「不是 X 而是 Y」改用「X 不等于 Y」「与其说 X 不如说 Y」。
所以规则一律写成**「点名句式 + 配对改写」**。

**判据用「密度异常」，不用「出现即错」。** 新模型普遍被硬编码禁掉某些特征后，
密度反转反而成了新指纹（逗号句号异常密集、一处破折号都没有）。规则自己会造出下一个指纹。
§2 的分级只对**惯用义**生效：一个词在字面义上使用时，按 §1 保留，不受所在级别约束
（最容易被误杀的三个是「闭环」「对齐」「链路」，见 §1）。
**改写示例里的数字只是结构示意。** 原稿没有的就删，或标「待补」——**不得补造**。
否则这份改写表本身就成了教模型编数据的范本。

**配额管内容，阈值管诊断。** 禁止的是**内容配额**（每页写几个结论数字、全文某术语出现几次）；
本文件给的是**诊断阈值**（成稿后多少个词算多）。二者不冲突。
另有一类**版式密度**（每页几个信息单元、字号种数、「每页一个论点」这类结构上限）不在此列，
违规动作是拆页／重排，见 SKILL.md §3 的区分表。

## 1. 别误杀：这些不是 AI 味

语域决定一切。以下出现在**对应语域**里是标准用法，不要动：

| 场景 | 保留 |
|---|---|
| 事故报告 / 变更日志 / 技术方案 | 根因、收口、收敛、落盘、幂等、漂移——工程术语；「闭环」指控制回路的**字面义**（如流程图里的闭环回路、审查流程的闭环）时同样保留 |
| 版式 / 数据 / 结构语境 | 「对齐线」「两版对照对齐」；「链路」指真实的调用链 / 网络链路——**字面义，不是黑话**。⚠️ 这条**不是**「对齐」的通用豁免：指沟通、认知、目标层面的一致时仍按黑话处理 |
| 技术描述里的被动 | 「数据经清洗后入库」——技术语域的被动是正常的 |
| 真有排名的场合 | 有数据支撑的「最」可以用 |
| 一句里的四字词 | 偶尔一个可以，问题在成片 |

## 2. 词的密度阈值

**一级：惯用义命中即改**（无阈值，出现就替换；字面义见 §0 第 4 段与 §1）

- **互联网黑话**：赋能→帮／支持；深耕→做了很久；聚焦→关注；助力→帮；打造→做／建；引领→带头；
  闭环→从头到尾；抓手→切入点；打通→接通；对齐（**仅在指沟通、认知、目标层面的一致时**）→确认口径；复盘→事后过一遍；链路（**仅在指组织黑话时**）→流程；
  拉通→串起来；沉淀→留下来／存成文档；心智→用户印象；生态位／组合拳→删掉，说具体是什么
- **假大空修饰**：全方位、多维度、高质量、沉浸式、一站式、全链路、端到端、全场景 → 具体列举或删
- **虚动词／名词化**：助力、致力于、旨在、通过……来……、对……进行了……、实现／完成（把动作名词化再用激活动词）、
  具备……能力、拥有……特性、即可、便可、仅需

  > 「实现」「完成」两极分化，判据是**删掉后有没有丢信息**：
  > 作**名词化空动词**（「实现了效率提升」→「效率提升」，信息不变）归本档，命中即改；
  > 作**本义**（「实现了预期目标」→ 丢了「达成」这个动作）保留。
- **填充词**：在很大程度上、一定程度上、某种意义上、进一步、不断地、持续地、更加、愈发、越来越、
  切实、真正、实实在在地
- **伪深度**：底层逻辑→根本原因；认知升级→学到了什么；思维模型→想法／方法；第一性原理→从头想；
  范式转移→大变化；颗粒度→细节程度；飞轮效应→良性循环
- **公文套话**：高度重视、狠抓落实、不断加强、深入推进、全面贯彻、统筹推进、协同发力、形成合力、
  压实责任、闭环管理、举一反三、提质增效、降本增效、数智化、新质生产力
  → **统一换成「谁、做了什么、结果如何」**
- **意义拔高**：具有里程碑意义、标志着……的新篇章、开创了……先河、为……注入了新的活力、
  为……提供了有力支撑、奠定了坚实基础、树立了新标杆、引领行业迈向新阶段、交出了一份亮眼的答卷
- **宣传腔**：亮眼、瞩目、欣欣向荣、蓬勃发展、硕果累累、令人振奋、可圈可点、有目共睹、蒸蒸日上、
  日新月异、突飞猛进、如火如荼、方兴未艾、势不可挡

**二级：同段聚集才动手**

词：此外、与此同时、显著、有效、全面、积极、持续、充分、恰恰、正是、无疑、可谓、堪称

阈值：短段（<100 字）同段 **≥2 个**；长段（≥100 字）**≥3 个**。散落不同位置可放行。

> **「进一步」两极分化**，判据是**删掉后有没有丢信息**（不是「句子还成不成立」）：
> - 虚词填充：「进一步优化」→「优化」，**信息不变** → 归**一级·填充词**，删
> - 实义：「进一步实验表明……」→「实验表明……」丢了「接下来这一轮」这层时间信息 → 保留
>
> 「实现／完成」同理，见 §2 一级·虚动词条。

**连接词另算**：此外，／与此同时，／不仅如此，／更重要的是，／除此之外，／值得注意的是，／
毫无疑问，／不可否认，／综上所述，／由此可见，
→ 直接说下一句。删掉九成，文章不会断。

> **「然而」不在此列，也不在上面的二级词表里。** 转折是论证的关节，不是修饰。
> 实测研究显示人类学术写作者**频繁使用** but / however / although
> （Desaire et al. 2023, *Cell Rep Phys Sci* 4(6):101426，DOI 10.1016/j.xcrp.2023.101426，摘要）；
> 而人写的文本里 discourse markers **不比模型少**——人类均值 0.57、GPT-3 为 0.52、GPT-4 为 0.36
> （Herbold et al. 2023, *Sci Rep* 13:18617, Table 3，DOI 10.1038/s41598-023-45644-9；
> 同文亦报告人与 GPT-3 在该项上**无显著差异**）。
> ⇒ 判据是问**这个转折之后有没有新信息**：没有，就整段删，别去删那个转折词。
> 证据档位：**【文献结论】**（两项均为同行评议期刊，已取原文核对）。
> ⚠️ 但两项研究都测的是**英文**写作，**不能直推中文**。它们只能支持「不要一刀切删转折词」，
> **不能反过来要求多用**。

**三级：全文密度才动手**

词：重要、关键、核心、创新、优化、提升、推动、确保、促进

阈值：<200 字同词 **≥3 次**；200–1000 字 **≥5 次**；>1000 字占比 **>0.5%**。

（「实现」的两极分化说明见 §2 一级·虚动词条。）

**「最」字**：一段里 ≥3 个没有依据的「最」（真实的最高级）又拿不出数据 → 换具体描述或删。
有排名就写出依据。

## 3. 改写对照

### 3.1 对仗与骨架

| 原文 | 改写 |
|---|---|
| 这套方案不是简单的工具替换，而是一次流程重构。 | 这套方案把审批从五步压到两步。 |
| 不在工具，在用工具的人。 | 同一套工具，两个人用出来的效果能差一倍。 |
| 本工具功能强大、操作简便、界面美观，让你事半功倍。 | 装上就能用，常用功能在第一屏，不用翻菜单。 |
| 在用户体验方面，我们做了优化。 | 登录页加载从 3 秒降到 0.8 秒。 |
| 通过引入新架构，从而提升了系统稳定性。 | 换了新架构后，过去半年没再出过事故。 |
| 我们对流程进行了优化，使效率得到了提升。 | 我们改了流程，跑得更快了。 |
| 该方案的建立对于保障系统稳定运行具有重要意义。 | 该机制在数据库连接断开后自动重连，平均 3 秒恢复。 |
| 更智能、更高效、更人性化。 | 删——换成三个不同量级的具体指标，或只留一个真的。 |

### 3.2 翻译腔（现有中文产出里最大的一块，常被漏掉）

翻译腔来自英文句式直译，比英文那套词表更隐蔽。

| 原文 | 改写 | 病灶 |
|---|---|---|
| 当你打开应用的时候，它会自动检测网络，然后它会为你加载数据。 | 打开应用，自动连网、加载数据。 | 代词过密 |
| 这个问题已经被我们很好地解决了。 | 这个问题我们修好了。 | 「被」字句滥用（替换库见本节下方） |
| 用户们反馈说 | 用户反馈说 | 复数加「们」 |
| 作为一个做了五年后端的人，我认为有风险。 | 我做了五年后端，这个方案我觉得有风险。 | As a… 直译 |
| 这是我们今年最重要的更新之一。 | 这是今年最重要的一次更新。 | one of the… 直译 |
| 这套设计能接住高并发，不会被流量击穿。 | 这套设计扛得住高并发，流量上来也不会宕。 | catch／break 直译成体感词 |
| 逻辑很清晰：先建索引，再查询。 | 先建索引，再查询。慢在每次都全表扫。 | 形容词＋冒号，替读者下判断 |
| 工程上的现实比这些数字更难看。 | 真跑起来，QPS 只有压测的一半。 | 抽象名词当主语 |

### 3.3 公文体 → 办公体（工程汇报的主战场）

| 原文 | 改写 |
|---|---|
| 下一步，我们将高度重视该问题，进一步加强统筹协调，压实各方责任，形成工作合力，确保各项举措落地见效。 | 下周我把三个部门拉进一个群，订单异常由客服直接 @ 技术处理，处理结果记在同一个表格里。 |
| 我们需要和各方对齐一下颗粒度，用组合拳打法赋能增长。 | 我周一和另外两个组确认了统计口径：按订单数还是按金额。先用订单数。 |
| 随着人工智能技术的飞速发展，越来越多的企业开始关注智能客服。在这样的大背景下，我们公司也开始了探索。 | 我们去年双十一的客服排队峰值是 400 人，最长等 11 分钟，所以今年试了智能客服。 |
| 综上所述，该方案在成本、效率、体验三方面均具有明显优势，值得进一步推广。 | 这套方案比原来省了两个人天，我们下个月在另一个仓也上。 |

**判据（§3 全体适用）**：改写后每个小句的主语和谓语**是不是都在承担信息**。
只加分量不加信息的半句，删。

**「被」的替换库**（针对 3.2 里的「被字句滥用」）：受、挨、遭、获、经、为…所…，
以及直接用主动句——「这个问题**我们修好了**」比「这个问题**已经被解决了**」信息更多。
**保留「被」的场合**：受事是唯一重要的主体，或施事不重要/未知（「数据被清洗后入库」）。

### 3.4 结构级：前饰 vs 后饰（中文最有效的一条）

上面的对照表多数是**词级**判断。这一条是**结构级**的，且有一个明确动作：**把长定语拆到后面**。

> 「目前的白话文，不知何故，几乎一律前饰，似乎不懂后饰之道。」
> 「**前饰句是关闭句，后饰句是开放句。**」——余光中

| 前饰（默认写法） | 后饰（改写） |
|---|---|
| 我见到一个长得像你兄弟说话也有点像他的陌生男人。 | 我见到一个陌生男人，长得像你兄弟，说话也有点像他。 |
| 我们提出了一套能够在低标注成本条件下保持稳定召回率的异常检测方法。 | 我们提出了一套异常检测方法，标注成本低，召回率稳定。 |
| 这是一个由三方共建、覆盖全流程、贯通上下游的数据治理平台。 | 这是一个数据治理平台，三方共建，覆盖全流程，上下游贯通。 |
| 这是一个格式尚未最终确定、需要在下个月定稿前完成多方确认的评审材料模板。 | 这是一份评审材料模板，格式还没定，下个月定稿前要和各方便确认。 |
| 我们提出了一种能够在部分标注缺失、类别分布不均衡的真实业务数据上保持稳定表现的异常检测方法。 | 我们提出了一种异常检测方法，在真实业务数据上表现稳定——这些数据有不少标注缺失，类别分布也不均衡。 |

**判据**：定语里**并列了三项以上**，或定语长到**读的时候要回头重来一遍**——就该后置拆句。
（「几个『的』」只是**症状提示**，不是硬阈值：单一个「的」也可能带出一长串修饰。
按读起来是否憋气判断，不要数「的」）。

**注意它和「删修饰词」不是一回事**：删修饰词是减信息，后饰是**把信息从名词前面挪到后面**。
信息一个不少，句子却从「关闭」变成「开放」，读者不用憋着一口气读完才等到中心词。

**不是所有前饰都改**：短定语（三个字以内、「基于规则的检测方法」这类专有说法）保持原样。
这条针对的是**句子读起来要回头重来一遍**的那种长定语。

> 证据档位：**从业经验**（余光中的散文论述，非语言学实证）。

### 3.5 句子级手术（改不动的句子用这个）

前面的词表管「哪些词有问题」，这一节管「**一句话从哪开始改**」。逐句过，只在卡住的句子上用。

```
1. 找人物。这句话在讲谁、什么？找不到主体 → 这句在说空话，整句考虑删。
2. 提主语。那个主体是不是语法主语？不是 → 提到主语位。
3. 还原动作。主体做了什么？它是不是谓语动词？
   被做成了名词（「对…进行了…」「作出…」「…的优化」「进行…」）→ 还原成动词。
4. 量距离。主语到动词隔了几个词？隔太远 → 把插入成分挪走或拆句。
5. 看句末。这句最该被记住的一件东西，在不在句末？不在 → 挪到句末。
6. 接下一句。下一句开头，是不是接住了这句句末的东西？
   接不住 → 不是文笔问题，是论证断了。回去补一环，别在这儿改字。
```

**第 6 步是这套流程里最值钱的一步。** 它把「读起来别扭」升级成**结构诊断**：
如果一句结尾抛出的新信息，下一句完全不接，通常说明中间缺了一环论证——
这时改句子是白改，要回去补逻辑。

> 证据档位：第 1–5 步合并自四套成体系的写作方法（Gopen & Swan 的句末重音、
> Williams 的「主角—动作」、Lanham 的 Paramedic Method、余光中的中文论述），属**文献结论 + 从业经验**混合。
> **第 4 步的「隔几个词算远」不给数值**：英文有「12 词」的经验值，中文没有对应研究，
> 机械按字数换算会得出荒谬规则。按你自己的语感判断，不要引入假精度。

## 4. 结构级反模式

句式之外还有结构层面的模板味，往往比词更伤。

**段落模板机**：每段都是「总—分—例—结」四拍，每段长度接近，小节之间长度也接近。
真实内容是不齐的——话题复杂就长，两句能说清就两句。**这解释了为什么强制对称的内容配额
会让产出更像机器：配额强制对称。**

**对称强迫症**：三优三劣、五步流程、等长小节。数字凑得越整齐越可疑。具体形态与改法：

| 形态 | 例 | 改法 |
|---|---|---|
| 对仗句通篇复用 | 「不是简单的工具替换，而是一次流程重构」 | 说实际发生了什么（见 §3.1） |
| 凑整齐的「第一、第二、第三」 | 三点其实只有两点独立，第三点是第二点的重述 | 合并，或只留真有的那几条 |
| 填空式三问三答 | 「是什么／为什么需要／没有会怎样」逐节套 | 按内容需要组织，不按模板 |
| 固定骨架反复套 | 每节都是「做成了什么／带来什么／证明了什么」 | 换说法，或直接写内容 |
| 冒号揭底 | 「逻辑很清晰：先建索引」「问题很直接：太慢了」 | 删掉前半句判断（见 §3.2 表） |
| 同一种开头或收尾 | 每页「这一页是……」，每节「一句话：……」 | 删掉这段引子，直接进内容 |
| 排比与口号堆叠 | 「更智能、更高效、更人性化」 | 换成一个有数据的指标 |

**一条判据管全部**：把这份稿子里**重复出现的句式**抽出来排成一列，超过两三条同形的，就是模板在说话。

**限定词大游行**：可能、或许、在某种程度上、在一定条件下 连用。
人写的是「这更快」或「我们还没测」。

**每段首词都是过渡词**：扫一遍段首，全是「此外／与此同时／更重要的是」→ 重写。

**「挑战与展望」式收尾**：「尽管面临诸多挑战，前景依然广阔」。判据不是提不提挑战，
而是**有没有这个固定公式**。真人常停在一个还没解决的问题或一个具体的下一步上；
结尾比事实本身还圆满，就删到只剩确实知道的部分。

**标题在首句复述**：小节标题叫「性能」，首句写「速度很重要」——删掉首句，从第二句开始。

**列表双向都错**：句子里有 ≥3 项并列，该拆成列表；本该一句话讲清的对比，被做成两列表格
、两三句信息塞进 bullet，是反向错误。**该是一句话的地方别用列表撑版面。**

**残留「上一版」叙述**：正文在讲「这个写法替换了什么」。上一版只属于 changelog。
改写：不写「新增此函数替代了 O(n²) 的朴素遍历」，写「此函数用哈希表实现 O(1) 查找」。

**格式装饰**：关键词满屏加粗、每两三句一个小标题、整句整句列点、【】段头、emoji 引导、
一句一段满屏短句、段落间分割线、「包括以下几点：」冒号清单。
**判据：这个格式你会不会打进给同事的微信里？不会，那多半也不该出现在汇报正文。**

**标点痕迹**：破折号一段 ≥3 处回头看（按功能替换：引出判断→句号，补充→括号，总结→冒号）；
半角逗号混进中文段、中文括号里用英文标点。
**机器残留必删**：未填占位符 `[在此插入…]`、`2025-XX-XX`、`INSERT_SOURCE_URL`、`[cite: 1]`、`utm_source=…`。

## 5. 写完怎么用

1. **生成阶段只写内容，不套这份表**——对 LLM 而言「不是 X 而是 Y」是划定类别边界的关系算子，
   生成时强行回避会让表述变含糊。
2. **定稿前扫一遍**，按 §2 的阈值判定，§3 的方式改写。
3. **扫结构再做一遍 §4**。句式干净但每段四拍的稿子，读起来一样是机器写的。
4. 一级词改完再看二级、三级——**不要一上来就按密度阈值做全文替换**，那会造成另一种整齐。
